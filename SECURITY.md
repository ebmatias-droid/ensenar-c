# Seguridad

No publiques vulnerabilidades explotables como issues públicos. Usa la función **Report a vulnerability** de GitHub en la pestaña Security del repositorio para enviar un aviso privado. Incluye los pasos para reproducir el problema y su impacto; no incluyas datos personales de usuarios.

La app local guarda las cuentas en `.private/` y requiere una cuenta para servir el curso. Mantén esa carpeta fuera de Git y protege la clave inicial de administración.
