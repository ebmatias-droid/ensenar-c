# Seguridad

No publiques vulnerabilidades explotables como issues públicos. Usa la función **Report a vulnerability** de GitHub en la pestaña Security del repositorio para enviar un aviso privado. Incluye los pasos para reproducir el problema y su impacto; no incluyas datos personales de usuarios.

El curso no tiene cuentas, contraseñas ni sesión: cualquier persona con el enlace puede acceder. No envíes contraseñas, datos personales ni secretos a través del sitio. El avance se guarda solo en el almacenamiento local del navegador.

El servidor local únicamente entrega una lista permitida de archivos estáticos del curso. Los datos privados que quedaron de la versión anterior viven en `.private/`, no se sirven por HTTP y siguen excluidos de Git.
