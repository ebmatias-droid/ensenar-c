# Solicitudes y contribuciones

C / escuela es un proyecto con derechos reservados y no acepta contribuciones de código o contenido sin autorización previa y por escrito del titular de los derechos.

Puedes usar GitHub Issues para informar un error o proponer una mejora. No incluyas código copiado, credenciales, datos personales ni información confidencial. Abrir un issue o enviar un pull request no concede derechos sobre el proyecto ni cambia su licencia.

Si se autoriza una contribución concreta, la autorización y los términos de incorporación se acordarán por escrito antes de enviarla. Consulta [LICENSE](LICENSE).
